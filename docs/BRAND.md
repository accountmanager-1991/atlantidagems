**Identity:** Concept A · "Caribbean Sun" seal with Dominican Republic silhouette at center
**Released:** 2026-04 (Session 14)
**Status:** Live on the website. Used across all social channels and print.

---

## 1. Logo

### Concept
A circular seal divided in half by a gold horizon line. Top half: amber sunburst (Dominican sun). Bottom half: larimar waves (Caribbean sea). Center: a real geographic outline of the Dominican Republic with three pinned markers — larimar at Barahona (south), amber at Puerto Plata (north), Santo Domingo (capital). "A" letter in the amber hemisphere, "L" in the larimar hemisphere. Outer double gold ring.

### Rationale
The seal tells the brand's origin story in one glance: the sun, the sea, the island, and the two stones — pinned to the actual places they're mined. No other jewelry brand uses this signature.

### Don'ts
- Don't recolor the gradients — they're tied to the actual stone colors.
- Don't stretch, skew, or rotate the seal.
- Don't add drop shadows or outer glows.
- Don't place on a low-contrast photo without keeping the gold ring intact (use a backdrop circle if needed).

## 3. Typography

Three typefaces, loaded from Google Fonts:

| Font | Use | CSS variable | Weights used |
|---|---|---|---|
| **Cinzel** | Headings (all-caps, brand name, page titles) | `--font-heading` | 400, 500, 600, 700 |
| **Cormorant Garamond** | Body text, descriptions, longer copy | `--font-body` | 300, 400, 500, 600, italic |

For print designs, install the same fonts locally before exporting.

## 5. Print — Business Cards

`brand-kit/03-BUSINESS-CARD-2026-04/`

- **Trim size:** 3.5" × 2" (1050 × 600 px)
- **Bleed:** 1/8" all sides — design canvas: 3.625" × 2.125" (1125 × 675 px)
- **Safe zone:** 1/8" inside trim
- **DPI:** 300
- **Crop marks:** baked into corners

| File | Purpose |
|---|---|
| `card-front-light.svg/.png` | Logo + wordmark on cream |
| `card-front-dark.svg/.png` | Logo + wordmark on navy radial |
| `card-back-light.svg/.png` | Contact info on cream |
| `card-back-dark.svg/.png` | Contact info on navy |

To customize before printing: open the SVG in Illustrator/Inkscape/Figma, edit the phone number placeholder (`+1 (809) ___ ____`), tweak handle/email if needed, re-export.

Print houses tested: Vistaprint, Moo, Got Print, local press. The PNG works for all; some accept the SVG directly.

## 6. Brand Guide PDF

`brand-kit/00-BRAND-GUIDE/Ambar-Larimar-Brand-Guide.pdf` — 8 pages:

1. Cover (logo + brand name)
2. Brand story (mission, promise, voice)
3. Logo system (mark, lockup, do/don't)
4. Color palette (12 swatches with hex/RGB/CMYK)
5. Typography (Cinzel · Cormorant · Montserrat specimens)
6. Social spec sheet (table of every asset, size, theme, use)
7. Print & business card specs
8. Resources (file paths, regen commands)

Send this to printers, agencies, freelancers, or partners as a single source of truth.

**Note:** the PDF substitutes Helvetica-Bold/Times for Cinzel/Cormorant because pdfkit can't load Google Fonts at edge runtime. Visual approximation, not pixel-perfect type — for that, use the brand-preview HTML pages or print designs with the actual fonts installed.

## 10. Regenerate commands

Run any of these to rebuild the corresponding artifacts:

```bash
# Logo PNGs (every standard size + favicons)
node scripts/export-logo-pngs.mjs

# Social kit (banners, IG templates, Etsy)
node scripts/generate-social-kit.mjs

# Print-ready business cards
node scripts/generate-business-card.mjs

# Brand guide PDF
node scripts/generate-brand-guide-pdf.mjs

# Reorganize everything into the per-platform Drive folders
node scripts/organize-kit-for-drive.mjs
```

After running any of the first four, you can re-run the organizer to refresh the Drive-ready folders.

## 11. How to update the brand

### Change a brand color
1. Edit `src/app/globals.css` (the `--color-*` token).
2. Edit `scripts/generate-social-kit.mjs` and `scripts/generate-business-card.mjs` (the `P` palette object).
3. Edit `scripts/generate-brand-guide-pdf.mjs` (the `PALETTE` array).
4. Re-run all four generator scripts + the organizer.

### Change the logo
1. Replace `brand-kit/01-LOGOS/final-2026-04/logo-mark.svg` (and `logo-horizontal.svg`).
2. Re-run `scripts/export-logo-pngs.mjs` to regenerate all PNG sizes.
3. Re-run `scripts/generate-social-kit.mjs` and `scripts/generate-business-card.mjs` (they read the master SVG).
4. Re-run `scripts/generate-brand-guide-pdf.mjs`.
5. Re-run `scripts/organize-kit-for-drive.mjs`.
6. Copy the new `mark-400.png` and SVG into `public/images/logos/` if changing the URL.

### Add a new platform / size
Edit `scripts/generate-social-kit.mjs` — the `banners` array or `igTemplates` array. Re-run the script and the organizer.
